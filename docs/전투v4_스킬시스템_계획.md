# 전투 v4 — 종·원소·악세 스킬 시스템 (2026-07-25 확정)

> 다음 세션 첫 작업. 이 문서대로 구현하면 된다.
> 사장님 확정 발언: "펫 종류는 같은 공격 행동, 원소에 따라 효과가 다르게.
> 기본 공격(종) + 재질 스킬 + 악세 패시브. 근접캐는 근접 스킬, 원거리는 원거리 스킬."

## 확정 구조 (3층 — 기획 원문 회귀+발전)

```
① 종(코어)  = 스탯 4종 + 기본 공격 방식 + 교전 타입(근접/원거리)
② 원소(재질) = 기본 공격 온히트 효과 + 원소 스킬(쿨타임 자동 발동, 종 타입에 맞는 벌)
③ 악세      = 패시브 스킬 (기획 10종 — 추후)
```

## 원소 스킬 두 벌 (근접형/원거리형)

| 원소 | 근접형 | 원거리형 | 상태 |
|---|---|---|---|
| 🔩 금속 | 우우웅(0.85s 장전) 쾅 — 광역+에어본(넉백X) | 강철 파편 산탄 | 근접형 완성 (PetUnit.DoStrike Metal) |
| 🪨 돌 | 점프 내려찍기 — 착지 광역+약넉백 (착지점은 적 '앞') | 바위 던지기(착탄 광역) | 근접형 완성 (JumpAdvance) |
| 🌿 나무 | 덩굴 채찍 — 전방 휩쓸기 (신규) | 잎사귀 3연타 타타탁 | 원거리형 완성 (burstLeft) |
| 🔥 불 | 화염 방출 — 주변 폭발+화상 (신규) | 기모아 불덩이 팡 | 원거리형 완성 |
| 💧 물 | 물기둥 솟구침 — 주변 밀침 (신규) | 물총 속사(0.38s, 근소넉백, 직선탄) | 원거리형 완성 |
| ⚡ 번개 | 방전 — 주변 지지직+슬로우 (신규) | 낙뢰 볼트(FX.Bolt)+슬로우 1.6s | 원거리형 완성 |

## 온히트 효과 (기본 공격에 얹힘)
- 🔥 화상(지속딜, 수치 미정) / 💧 근소 밀침(body×0.03) / ⚡ 슬로우(1.6s, 이속 55%)
- 금속·돌·나무 = 무효과 (대신 스킬이 큼) — 효과 인플레 방지, 사장님 승인 대기 아님(제안 수용됨)
