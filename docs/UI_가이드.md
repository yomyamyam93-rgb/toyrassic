# 토이라식 UI 제작 가이드 (v1 — 심플)

업계 표준(8pt 그리드, 게임 HUD 배치 관례, 가독성 규칙)을 우리 게임에 맞게 정리.
**모든 UI는 이 문서의 수치를 따른다. 임의 값 금지.**

## 1. 기준 해상도·그리드
- 기준 캔버스: **1920×1080**, CanvasScaler `Scale With Screen Size`, match 0.5
- **8pt 그리드**: 모든 여백·간격은 8의 배수 (8 / 16 / 24 / 32)
- 화면 가장자리 안전 여백: **24px**

## 2. 타이포그래피
| 용도 | 크기 | 굵기 | 행간 |
|---|---|---|---|
| 제목(펫 이름 등) | 26 | Bold | 1.25 |
| 본문(수치·상태) | 18 | Normal | 1.35 |
| 캡션(힌트·보조) | 14 | Normal | 1.35 |
- 자간: 기본 0 (TMP 도입 시 한글 -1% 권장)
- 본문 흰색 95%, 보조 흰색 65% — **완전 흰색(100%)·회색 50% 이하 금지**
- 월드 위에 뜨는 텍스트는 반드시 그림자 or 외곽선 (배경 밝아도 읽히게)

## 3. 색
| 역할 | 값 |
|---|---|
| 패널 배경 | #14171C, 알파 72% |
| 내 체력 | #F56B61 (붉은 산호) |
| 펫 체력 | #5CE06B (초록) |
| 경험치·부화(진행) | #FFD647 (골드) |
| 강조·토스트 | #FFE073 |
| 위험 경고 | #FF4A3D |
- 색은 역할당 1개. 같은 역할에 다른 색 쓰지 않기

## 4. 패널·바
- 모서리 라운드 **12px** (전 패널 통일)
- 패널 내부 패딩 **14px**, 요소 간 간격 **8px**
- 게이지 바: 높이 — 주요(체력) **18px** / 보조(경험치) **10px**, 라운드 캡
- 바 구성: 어두운 배경(#000 60%) + 채움. 수치 라벨은 바 안 중앙 (12px)

## 5. 배치 관례 (업계 표준)
| 위치 | 내용 |
|---|---|
| **좌상단** | 내 상태 (캐릭터 HP, 펫 정보, 진행 게이지) |
| **우상단** | 재화·수집품 (알 개수 등) — 추후 미니맵 |
| **중앙 상단** | 토스트/알림 (3초 표시 후 0.5초 페이드) |
| **중앙** | 절대 상시 UI 두지 않기 (전투 시야) |
| **하단 중앙** | 상호작용 프롬프트 ("E — 알 넣기" 식) — 추후 |
| **좌하단** | 조작 힌트 (캡션, 은은하게) |
| **우하단** | 주요 행동 버튼 (모바일 대비) — 추후 |

## 6. 버튼 (추후 창·메뉴용)
- 최소 크기 **48×48px** (터치 대응), 텍스트 버튼은 높이 48 고정
- 주요(확인) 버튼 = 골드 배경+검정 글씨, 보조(취소) = 투명+흰 테두리
- 창(모달) 안에서: **확인은 오른쪽, 취소는 왼쪽** (콘솔·PC 관례)
- 호버 시 밝기 +10%, 클릭 시 스케일 0.96 (쫀득)

## 7. 애니메이션
- 등장: 0.15s 페이드+살짝 위로 (8px)
- 퇴장: 0.25s 페이드
- 숫자 변동: 즉시 (게이지는 잔상 바 방식 — 월드 체력바와 동일)
- 과한 흔들림·회전 금지 — 게임 화면이 이미 통통 튀므로 UI는 차분하게

## 8. 창(윈도우) 규격 — 인벤토리·스탯·제작
- 크기 **920×560**, 화면 정중앙, 배경 패널색(#14171C 88%) + 라운드 12
- 열기/닫기: **Tab** 토글, ESC 로도 닫힘. 게임은 멈추지 않음 (서바이벌 관례)
- 상단 왼쪽에 **탭 버튼 줄** (인벤토리 / 스탯 / 제작), 활성 탭 = 골드 하이라이트
- 인벤토리: **64px 슬롯 그리드**(간격 8), 아이콘 중앙 + 수량 우하단(14px)
- 제작: 좌측 레시피 목록(행 높이 56) — 이름·재료 표시 + 우측 제작 버튼,
  재료 부족 시 버튼 비활성(회색)·수량 빨간 표시
- 창이 열려 있는 동안 활·채집 입력 차단

## 9. 구현 규칙
- UGUI(Canvas) 코드 생성 — 씬에 수동 배치 금지 (SquadHUD 가 런타임 생성)
- 폰트: LegacyRuntime(OS 폴백으로 한글 지원). TMP 전환은 추후 일괄
- 신규 UI 는 반드시 이 가이드의 상수(SquadHUD 상단)를 재사용
