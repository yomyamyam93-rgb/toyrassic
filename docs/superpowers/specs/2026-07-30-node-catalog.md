# 노드 카탈로그 — 후보 전수 조사와 과학적 선별

2026-07-30. 알 원정 설계(같은 날짜 spec)의 노드 트리를 뒷받침하는 문서.
사용자 주문: "수십 수백 가지를 정리하고 그중에 괜찮은 것들을 골라서 과학적으로."

## 0. 과학 — 레버마다 실제 가치가 다르다 (전부 실측 근거)

노드 효과는 결국 아래 레버 중 하나를 당긴다. 같은 +15%라도 레버마다 값이 다르다:

| 레버 | 실제 효과 | 근거 (CLAUDE.md 실측) |
|---|---|---|
| 한 대 피해 +x% | 유효 화력 +x% — 선형, 보편 | 유효 화력 = (한 대÷간격)×동시타격 |
| 공속 +x% | 화력 +x% + **오버킬 감소** (잘게 때릴수록 낭비가 적다) | 오버킬 문턱 — 티라 한 대 66.5 에 S 체력 70 |
| 치명타 p%×2배 | 기대값 +p% 지만 **몰아침** — 큰 놈에 강하고 잔몹엔 오버킬 낭비 | 같은 문턱 논리의 역방향 |
| **팔 길이 +x%** | 근접 동시타격 **+2x%** (면적에 제곱으로) | 면적 = 각도 × 팔² — 이걸 놓쳐 오진 4회 |
| 체력 +x% | 버티는 시간 +x%. ★문턱을 넘으면 두 배 가치, 못 넘으면 죽은 스탯 | "몇 대에 죽는가가 물량의 가치를 결정" |
| 마릿수 +x% | **화력·체력·점유 면적이 동시에** +x% — 가장 강한 레버, 비싸야 한다 | 예산÷등급 구조 |
| 사거리 +x% | 느린 놈 상대 우위 확대. 삼각형 방향 보존 — 비교적 안전 | "사거리는 오히려 올리고 싶은 축" (사용자) |
| **이속 +x%** | ★★위험 — 삼각형 자체가 이속 순위(늑구>딜롭>티라)로 성립 | "PatternMoveSpeed 를 1로 올리면 아무도 원거리를 못 잡는다" |

**금지 목록 (삼각형 파괴범):**
1. **무조건부 이속+** — 순위표가 뒤집히면 어떤 숫자로도 상성이 안 닫힌다.
2. **원거리 이속+** — 법칙③(빠른 떼가 원거리를 덮친다)의 사망 선고.
3. **카이팅 무제한화** (kiteCooldown 감소 과다) — ②변이 압승으로 넘어간다 (76% 전례).
4. **축 오염** — 노드가 방식·등급의 원형을 바꾸면 안 된다. 배수만 얹는다
   (2026-07-29 "같은 사고가 네 번" — 축 셋은 독립이다).

**선별 기준 5개:**
- ①삼각형 보존 ②측정 가능 (F12 리그로 전후 비교가 되나) ③결정을 만드나
  ("항상 옳은" 수치는 길목에, "상황 따라"인 전용 효과가 갈래 끝 핵심)
- ④**보이나** ("유니티 열고 눈으로 보이는 결과" — 어그로 맥동·착지 충격파처럼
  화면에 보이는 효과를 우선) ⑤구현 비용.

## 2. 선별 결과 — 아키타입 트리 (PoE 문법, 2026-07-30 사용자)

★사용자 확정: "노드가 너무 작지 않게. 포이처럼 **핵심으로 가는 길의 기본 스탯이
핵심과 연관**되고, 부대를 **전략적으로 짤 플레이스타일**이 나와야 한다 —
물량전으로 밀어붙이는 타입, 강한 소수로 휩쓰는 타입."

**PoE 문법 세 줄:**
1. **키스톤은 수치가 아니라 규칙을 바꾼다 — 그리고 반드시 대가가 있다.**
   대가가 없으면 "다 찍는 순서"만 남고 빌드가 안 갈린다.
2. 키스톤으로 가는 길목의 소노드는 **같은 계열** — 걷는 길이 곧 빌드 선언.
3. 다 못 찍는다 — 레벨 상한이 "무엇을 포기하나"를 강제한다.

### 키스톤의 과학 — 대가가 상성을 지킨다

- **끝없는 무리**: 예산+60%는 화력·체력·점유 동시+60%. 피해-25%를 물려 순화력
  +20%로 누르고 **몸 수는 그대로 +60%** — 포위·소모전 특화. 광역(법칙①)에
  더 크게 벌받는다 — 삼각형이 오히려 선명해진다.
- **왕의 소수**: 마릿수 절반 = 광역의 표적이 절반. 개체 문턱("몇 대에 죽나")이
  확 올라가 **법칙①을 정면으로 카운터하는 빌드** — 대신 총화력 0.85배로 느리고,
  소수라 저격·집중사격(단일 화력)에 취약. 새 상성 축이 공짜로 생긴다.
- **거점 포격**: 화력을 받는 대가가 **도망 능력** — 흩뿌리기가 카이팅을 안 하는
  것과 같은 문법이라 검증된 안전한 거래다. 빠른 떼(법칙③)에게 더 크게 벌받는다.
- **우두머리 사냥**: 부대를 깎아 본체에 싣는다. 기준선(캐릭터 ≈ 펫 3마리)이
  이동하는 유일한 빌드 — 재측정 필수.

### 구조 규칙

- **소노드도 작지 않다** (+10~15%) — "찍은 티가 안 나는 노드"는 두지 않는다.
- 레벨 16 기준: 키스톤 1개 + 다른 가지 중형까지. **키스톤 2개는 불가능**하게
  포인트를 잡는다 (아키타입 = 배타적 선언).
- **재배치는 부화터에서만** — 밴드가 편성 교체를 강제하는 설계와 키스톤 고정이
  충돌하지 않게 하는 밸브. 공짜 재배치(아무 데서나)는 선언의 무게를 죽인다.
- 금지 목록(§0)은 아키타입에도 그대로 — 키스톤이라도 무조건부 이속은 없다.
- 확장은 아키타입 사이 **가교 노드**(하이브리드)와 가지당 두 번째 키스톤으로.
  §1의 후보(부대 흡혈·낙하 충격·포란 본능·정찰안)가 그 재료다.

## 3. 검증 계획

1. **아키타입 × 밴드 행렬** — 4개 빌드로 밴드 1~4를 각각 주행. 판정:
   모든 밴드를 어떤 빌드로든 깰 수 있되, **빌드마다 쉬운 밴드·지옥 밴드가
   달라야** 성공 (한 빌드가 전 밴드 최적이면 키스톤 대가가 모자란 것).
2. F12 리그로 삼각형 재측정 — 키스톤 효과를 켠 상태로 세 변 30~50% 유지 확인.
   특히 거점 포격(카이팅 포기)과 왕의 소수(문턱 이동) 후에 반드시.
3. 오뚝이 켜고 늑구 vs 티라 — 잔여 0% 전멸 5판이 어떻게 변하나.
4. 우두머리 사냥 빌드로 플레이어 유효 화력 재측정 (차징 포함 — CLAUDE.md 기준선 갱신).
