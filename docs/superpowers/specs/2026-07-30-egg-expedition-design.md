# 알 원정 (Egg Expedition) — 프로토타입 설계

2026-07-30 사용자와 브레인스토밍으로 확정. 정본 설계(3층 구조)를 뒤집지 않고,
그 위에 "여정 → 알 → 부화터" 루프를 얹는다.

**한 줄:** 스폰을 새로 깔고, 강한 펫의 알(마커 `named_37_31`)을 향해 지역 밴드를
뚫고 가서, 수문장을 이기고 알을 들고 탈출해, 부화터에서 깨워 부대에 넣는다.

## 확정 사항 (사용자 답변)

| 질문 | 확정 |
|---|---|
| 리셋 범위 | **A. 데이터만 리셋** — 인벤·보관함·스폰만 비움. 제작·채집·투척 시스템은 유지 |
| 난이도 게이트 | **지역 등급제** — 알에 가까울수록 강한 종·많은 무리 |
| 노드 재화 | **레벨업 포인트만** — 캐릭터 레벨업 1회 = 포인트 1 |
| 레벨의 주인 | **캐릭터 전용.** 펫은 종 고유 스탯으로 전부 동일 — 같은 종이면 완전히 같다 |
| 부화 규칙 | **부화는 오직 부화터에서** — "알은 따뜻한 곳에서만 깬다" |

## 난이도 — 레벨 없이, 밴드 4개가 "질문"을 던진다

★물량·조합 그 자체는 재미가 아니다 (사용자 우려 확인). **밴드마다 이전 밴드의
승리 공식을 벌주는 질문**이어야 편성 교체(=재미)가 강제된다. 상성 삼각형의
세 법칙이 그 질문이다.

| 밴드 | 묻는 질문 | 정답 (플레이어가 발견) | 구성 예 |
|---|---|---|---|
| 1 시작 지대 | 없음 — 배우는 곳 | 아무거나 이김, 첫 펫 수집 | S 소수 (늑구·꼭꼬) |
| 2 | **뭉친 S 떼** (물량) | 넓게 때리는 놈 (법칙①) — 여기서 광역 펫 획득 | S 대군 |
| 3 | **포수 혼성** (뒤에서 쏨) | 빠른 떼로 덮치기 (법칙③) | M 근접 + 원거리 |
| 4 알 둥지 | **XL 수문장 + 호위** | 종합 시험 — 원거리로 거인(법칙②), 광역으로 호위 | 손배치 |

- 난이도 손잡이는 셋뿐: **①종 등급 ②무리 예산 ③조합**(원거리 섞임이 체감을 가장 바꿈).
- 구현: `PetSpawner`의 거리 기반(`tierPerMeters`)을 **밴드 테이블 조회**로 교체.
  밴드 경계는 시작점→둥지 경로 기준.
- **판정 기준: 같은 부대가 모든 밴드를 이기면 실패. 밴드마다 편성을 바꾸게 되면 성공.**
- 지루함 방어 둘: **싸움 전 정보**(무리 구성이 멀리서 보여야 — 편성 결정이 재미의
  본체) · **각본 있는 순간 2~3개**(좁은 길목 매복, 둥지 수문장 — 마커 손배치).

## 노드 트리 — 캐릭터 전용, 몬헌 무기 트리식

레벨업 시 스탯 자동 상승 없음. 포인트 1개 = 노드 1개. 프로토타입은 **가지 4개 ×
3노드 = 12노드** (레벨 12까지의 여정, 둥지 도달 즈음 핵심 1~2개 상태).

```
        [시작]
       ╱  │  │  ╲
   물량  데미지  사거리  치명타
```

| 가지 | 중간 노드 (캐릭터 스탯) | 핵심 노드 (부대 효과) |
|---|---|---|
| 물량 | 체력+ → 체력+ | 투척 소환 +2마리 (`throwBudget`+) |
| 데미지 | 힘+ → 힘+ | 펫 한 대 피해 +15% |
| 사거리 | 민첩+ → 힘+ | 원거리 펫 사거리 +20% |
| 치명타 | 민첩+ → 민첩+ | **내 편 전체** 15% 확률 2배 피해 |

- 중간 노드가 사용자가 원한 "핵심 찍으러 가는 길의 캐릭터 스탯"이다.
- 확장은 핵심 뒤에 더 큰 핵심을 세로로 잇는다 (몬헌식). 가지를 늘리지 않는다.

## 알 루프 — 원정 → 탈출 → 부화터

```
원정: 밴드를 뚫고 둥지로 → 수문장 격파 → 알 획득
  → 탈출: 집는 순간 둥지 일대 총어그로 — 쫓기며 부화터까지
  → 부화터 선택: 지도의 부화 전용 지역 중 한 곳 (지형이 다 다르다)
  → 부화: 작은 알 = 즉시 / 좋은 알 = 타이머 + 웨이브 디펜스
  → 강한 펫이 부대에 합류 — 돌아가는 길은 개선 행진
```

★몬헌 알 운반 퀘스트(시리즈 최다 원성)의 교훈: **재미는 수문장을 이기는 순간에
있고, 알은 트로피의 포장지다.** 포장 뜯기(장거리 운반·부화 대기)를 길게 하지 않는다.

## 부화터 — "큰 맵 속의 작은 맵"

- **개연성 한 줄: 알은 따뜻한 곳에서만 깬다.** 부화터 = 지열 분출구·온천가·태양석
  같은 "따뜻한 자리". 생김새가 지형 성격을 그대로 말해 준다.
- **손으로 고른 10~20곳** (수백 개 ✗ — 재미는 개수가 아니라 지형 성격 차이에서
  나온다). 좁은 길목·언덕 위·물가·개활지 — 부화터마다 디펜스가 다른 판이 된다.
  "가까운 데로 갈까, 좋은 지형까지 갈까"가 고민이 되는 밀도.
- **작은 알** — 올려두면 **즉시 부화.** 디펜스 없음 (모든 펫마다 디펜스를 시키면
  그것도 노동이다). ★프로토타입에는 둥지가 1곳(좋은 알)뿐이므로 작은 알은 **규칙만
  정의**해 둔다 — 일반 펫 획득은 기존 설계도 줍기 그대로. 작은 둥지들은 후속.
- **좋은 알** — 올리는 순간 **타이머가 뜨며 웨이브 예고**(준비 시간) → 야생이
  부화기로 진군 → 타이머 끝까지 버티면 부화. 웨이브 구성은 **그 지역 밴드
  테이블을 그대로 재사용**한다. 지면 알을 잃는다 — "어디서 깔까"가 무게 있는
  결정이 되는 이유.
- CLAUDE.md 「디펜스의 뼈대」 세 갈래(전투 종료 기준점 → 내 편 앵커 목록 /
  복귀 목적지 → 부화터 / 야생의 행선지 → 부화터로 진군)를 여기서 실제로 구현한다.

## 캐릭터 ↔ 펫 밸런스

- 방향: **캐릭터를 펫에 맞춘다** (펫 스탯은 리그전으로 잡은 값이 기준).
- 기준선은 CLAUDE.md의 "캐릭터 ≈ 펫 3마리" 를 유지하되, **차징 배수 포함해서 재측정.**
- 같이 갈 과제 (할 일 #4): 베기 이펙트 개편 · 화살을 에너지 빔(케찰식 3겹+플레어)으로,
  **관통** 지원, 차징 게이지에 따라 굵기 증감. 관통은 화력 변화라 재측정과 함께 잰다.

## 성공 기준

1. 시작→알 획득→부화까지 한 사이클이 실제로 돈다 (유니티에서 눈으로 보임).
2. 밴드마다 편성을 바꾸게 된다 (같은 부대로 전 구간 클리어가 안 됨).
3. 좋은 알 디펜스에서 부화터 지형이 승패에 영향을 준다.
4. 레벨 잔재가 코드에 없다 (펫은 종 스탯뿐).
